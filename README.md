# College-Advisor-AI
An AI-based educational platform that provides personalized college and career recommendations using web technologies, machine learning, and automated aptitude analysis.

 Features

- User login with OTP verification
- Aptitude-based career assessment
- AI-powered career prediction
- College and course recommendation
- Interactive user interface

Technologies Used

        Frontend
- HTML
- CSS
- JavaScript

         Backend
- Node.js
- Express.js
- MongoDB

        AI Model
- Python
- PyTorch
- Machine Learning

API
- Twilio API for OTP verification





- Integration with real college databases
- Improved ML prediction accuracy
- Personalized recommendations based on student profiles
